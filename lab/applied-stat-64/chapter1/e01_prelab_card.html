E01 实验前准备卡

适用实验：e01_inclass.ipynb

开始前先确认

  1. 已经打开 Jupyter Notebook，并进入 lab/applied-stat-64/chapter1 目录。
  2. 能看到 e01_inclass.ipynb，并成功打开文件。
  3. Notebook 右上角内核状态正常，可以运行代码单元。
  4. 已准备好在“实验信息”单元填写姓名、学号、班级和日期。

本次实验要完成什么

  1. 会区分 Markdown 单元和代码单元。
  2. 会运行、修改和重新运行代码，并理解 Notebook 执行状态。
  3. 会使用 print()、type()、f-string、基础比较与逻辑表达式。
  4. 能阅读一次简单报错，使用帮助或代码补全寻找修复线索。
  5. 能通过反向计算或重新运行核验程序结果。

最常用的两个操作

  1. 运行当前单元：Shift + Enter
  2. 新建单元后，注意把它切换成正确类型： Markdown 用来写说明，代码单元用来写 Python 代码。

如果卡住了，先按这个顺序检查

  1. 前面的单元是不是还没运行，导致变量未定义。
  2. 当前单元是不是写成了错误的类型，例如把说明写进了代码单元。
  3. 修改代码后是不是忘了重新运行当前单元。
  4. 报错是不是因为字符串和数字直接参与了计算。
  5. 如果结果混乱，重启内核后按顺序重新运行。

提交前最后检查

  1. 所有练习都已在原 Notebook 中完成。
  2. 代码、输出结果和必要说明都保留在文件中。
  3. 实验小结已经用 Markdown 完成，包含三级标题和项目列表。
  4. 已说明代码补全、帮助文档或 AI 工具的使用情况和核验方式。
  5. 重启内核后按顺序运行全部单元，除有意观察的报错外没有异常。

给学生的提醒

本次实验的重点不是做难题，而是形成“修改—运行—检查—解释”的基本习惯。练习中使用课程提供的模拟信息，不填写或传播无关的真实个人数据；AI 或代码补全给出的建议必须经过运行和核验。
