# E06 实验前准备卡

适用实验：`e06_inclass.ipynb`

## 开始前先确认

1. 如需继续使用个人成果，准备 E05 标准输出目录中的文件，或把 `e05_cleaned_records.json` 放到当前工作目录。
2. 个人文件缺少时，依次使用仓库官方检查点、当前目录的 `e05_cleaned_records_official.json` 官方副本；都没有时需要联网获取，核验后缓存到当前目录。
3. 知道 `USE_STUDENT_E05_OUTPUT = False` 会跳过个人标准输出和当前目录的个人同名文件，直接查找官方输入。
4. 已复习 Python 列表、列表推导式和二维列表。
5. 已复习 Chapter 3A 中的 `np.array()`、`shape`、索引、切片和向量化运算。

## 本次实验要完成什么

1. 从结构化记录提取非缺失数值并创建一维数组。
2. 检查数组维数、形状、元素数量和类型。
3. 完成索引、切片、标量运算和数组运算。
4. 比较循环与向量化写法。
5. 创建“记录数 × 2”的二维数值数组并核验记录对齐。

## 如果卡住了

1. 先查看准备单元打印的来源、实际路径和当前工作目录，确认记录数是否为 160；当前工作目录不一定是 Notebook 所在目录。
2. 个人成果核验失败时，先检查 E05；需要继续实验时可把输入开关改为 `False`。
3. 遇到形状错误时先输出 `.shape`。
4. 一维数组使用一个索引，二维数组通常使用“行、列”两个位置。
5. 不要为了让代码运行而删除缺失记录之外的正常数据。
6. 只有文件不存在才向后兜底；已有文件解析或核验失败不会自动换成官方数据。无法联网时，可手动下载官方检查点并按官方副本名称放到当前工作目录。

## 提交前检查

1. 有效学习时长数和完整数值记录数均已报告。
2. 循环与向量化结果已经核验。
3. 二维数组的两列含义明确且顺序一致。
4. 已完成实验小结并从头运行 Notebook。
