E07 实验前准备卡

适用实验：e07_inclass.ipynb

开始前先确认

  1. 输入与 E06 相同：个人 E05 标准输出 → 当前目录的 e05_cleaned_records.json → 仓库官方检查点 → 当前目录的 e05_cleaned_records_official.json → 联网获取并缓存官方副本。
  2. 知道 USE_STUDENT_E05_OUTPUT = False 会跳过前两个个人输入位置；本地无官方文件时，需要联网或手动下载官方副本。
  3. 已复习布尔比较、&、~ 和布尔筛选。
  4. 已复习 Chapter 3B 中的聚合、np.nan、np.isnan()、axis 和广播。
  5. 能解释 E06 中为什么数组形状和记录对齐需要核验。

本次实验要完成什么

  1. 使用 np.nan 保留缺失位置。
  2. 建立缺失掩码、有效值掩码和分组掩码。
  3. 完成有效样本量、均值、极值和标准差计算。
  4. 使用二维数组和 axis 检查完整记录。
  5. 使用广播完成两个字段的按列阈值判断。

如果卡住了

  1. 先确认所有一维数组长度都是 160。
  2. 多个条件组合时，每个条件都加括号。
  3. 统计前先检查用于计算的布尔掩码。
  4. axis=0 和 axis=1 不确定时，先结合数组形状画出行列。
  5. 输入异常时查看打印的来源、路径和当前工作目录；已有文件损坏或核验失败不会静默兜底，应修正文件或主动切换官方输入。

提交前检查

  1. 缺失数量、有效样本量和完整记录数均已输出。
  2. 两组有效样本量之和已经核验。
  3. 广播前后的数组形状已经检查。
  4. 没有把不同单位的字段直接按行求平均。
