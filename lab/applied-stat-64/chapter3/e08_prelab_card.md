# E08 实验前准备卡

适用实验：`e08_inclass.ipynb`

## 开始前先确认

1. 已复习 `np.random.default_rng()`、`random()` 和 `binomial()`。
2. 能使用二维数组、布尔判断、`sum(axis=...)` 和 `mean(axis=...)`。
3. 已复习 Chapter 2 的函数和循环，能够重复调用同一个模拟函数。
4. 知道本实验使用假想概率模型，不读取或解释真实学生数据。
5. 能区分“固定随机种子”和“每次调用都返回相同结果”。

## 本次实验要完成什么

1. 检查固定种子的可复现性。
2. 从基本随机数构造多项任务完成试验。
3. 独立走完“目标—假设—随机生成—事件判定—比例估计”流程。
4. 使用循环比较不同模拟次数并重复整组实验。
5. 运行课程提供的另一种随机生成方式并核验结果。
6. 提交包含模型限制的 Monte Carlo 实验报告。

## 如果卡住了

1. 每一步都先检查数组形状。
2. 核心任务只使用二维数组；重复整组实验时调用已有函数并收集结果。
3. 事件掩码应是一维布尔数组，每个位置对应一次模拟。
4. 估计值异常时先检查事件定义，不要只增加模拟次数。

## 提交前检查

1. 报告中包含种子、模拟次数、事件定义和估计值。
2. 至少比较了 100、1,000 和 10,000 次模拟。
3. 使用重复实验说明了估计稳定性的变化。
4. 明确说明假想模型不代表真实学生规律。

## 提前完成后的拓展

可以尝试使用三维数组一次生成多组重复实验；该任务不计入 90 分钟核心要求。
