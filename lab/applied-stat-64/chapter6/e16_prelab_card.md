# E16 实验前准备卡

适用实验：`e16_inclass.ipynb`

## 开始前先确认

1. 已确认 `student_analysis.csv` 和官方 E15 结果检查点存在。
2. 如需继续个人成果，已确认 E12、E15 输出文件存在且核验通过。
3. 已复习 Chapter 6B 中响应变量、解释变量、斜率、拟合值、残差和 \(R^2\)。
4. 能说明简单回归中的关联、预测和因果是不同问题。

## 本次实验要完成什么

1. 绘制学习时长与期末成绩散点图。
2. 使用 Statsmodels 拟合简单 OLS。
3. 提取截距、斜率和 \(R^2\)。
4. 绘制拟合线和基础残差图。
5. 复用 E15 结果完成最终可复现分析报告。

## 如果卡住了

1. 先确认公式左侧是 `final_score`，右侧是 `study_hours`。
2. 结果异常时检查是否颠倒响应变量和解释变量。
3. 残差图使用模型拟合值和残差，不是原始学习时长和成绩。
4. 写报告时读取 E15 结构化结果，不重新完成整个两组检验。

## 提交前检查

1. 已导出回归结果、拟合图和残差图。
2. 报告同时包含 E15 两组比较和 E16 简单回归。
3. 没有把斜率写成每名学生的确定变化。
4. 没有把 \(R^2\) 写成预测准确率或因果贡献率。
