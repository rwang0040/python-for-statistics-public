# E03 实验前准备卡

适用实验：`e03_inclass.ipynb`

## 开始前先确认

1. 已经打开 `e03_inclass.ipynb`。
2. 已确认 `lab/shared/samples/chapter2_records.json` 文件存在，并运行课程准备单元。
3. 能解释一条记录为什么是字典，多条记录为什么放在列表中。
4. 已复习比较运算、逻辑运算和缩进规则。
5. 知道分类规则中的边界必须公开且一致。

## 本次实验要完成什么

1. 使用 `if-elif-else` 对学习时长分类。
2. 使用 `for` 把同一规则应用到每条记录。
3. 完成筛选、组合条件、条件计数和累计汇总。
4. 使用基础列表推导式生成目标 alias 列表。
5. 用 4、8 和 7.9 检查分类边界。
6. 综合汇总两套分类结果；`while` 对照为提前完成后的拓展任务。

## 如果卡住了

1. 先只对一条记录写判断，再把它放入循环。
2. 筛选结果通常先建立空列表，再在满足条件时 `append()`。
3. 条件计数先把计数器设为 0。
4. 如果结果不对，逐条打印 alias、条件值和判断结果。

## 提交前检查

1. 分类规则与题目给出的边界一致。
2. 筛选结果没有修改原记录列表。
3. 循环结束后再计算平均值。
4. 已解释筛选、分类与计数的区别。

## 给学生的提醒

本实验处理的是已经结构化的小样本。`for` 和 `if` 首先用于逐条应用规则，不等同于文件清洗。
