# E02 实验前准备卡

适用实验：`e02_inclass.ipynb`

## 开始前先确认

1. 已经进入 `lab/applied-stat-64/chapter2` 目录并打开课堂版 Notebook。
2. 已确认 `lab/shared/samples/chapter2_records.json` 文件存在。
3. 能正常运行课程准备单元，且已完成实验信息。
4. 已复习列表的索引、切片和 `append()`。
5. 已复习字典的键、值和按键取值。

## 本次实验要完成什么

1. 直接运行课程准备代码，载入 8 条同源调查记录，不重新录入整批数据。
2. 使用索引、切片和字典键取得目标信息。
3. 亲手构造并追加一条记录。
4. 在副本上修改记录，避免意外改变课程设置数据。
5. 说明“列表中的字典”与表格行列的关系。
6. 提前完成时，可选做嵌套实验提交对象。

## 如果卡住了

1. 检查是否已经运行数据设置单元。
2. 列表按位置取值使用 `[]`，字典按键取值也使用 `[]`，但括号中的内容不同。
3. 最后一条记录可以使用索引 `-1`。
4. 修改记录前先确认修改的是原对象还是 `.copy()` 得到的副本。

## 提交前检查

1. 所有核心任务都有最终代码和输出。
2. 新增记录包含与课程样本相同的 8 个字段。
3. 没有删除或改写课程提供的数据设置单元。
4. 已完成实验小结并重新按顺序运行 Notebook。

## 给学生的提醒

本实验的数据由课程准备代码从同源样本载入；直接运行即可，不要求解释其中的 JSON 读取代码。手工输入只用于理解一条记录怎样构造，不承担数据采集任务。
