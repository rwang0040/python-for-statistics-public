E04 实验前准备卡

适用实验：e04_inclass.ipynb

开始前先确认

  1. 已确认 lab/shared/samples/chapter2_records.json 文件存在，并运行课程准备单元。
  2. 能区分函数的参数、函数体、返回值和调用结果。
  3. 已复习 E03 中的分类、筛选和累计规则。
  4. 知道 float("6.5") 可以转换，而 float("unknown") 会触发 ValueError。

本次实验要完成什么

  1. 任务 1–2：编写学习时长分类函数，并用预期结果核验分类边界。
  2. 任务 3–5：处理已规范化的课程记录，编写平均值和筛选函数，再复用它们生成摘要。
  3. 任务 6–7：使用 try-except 转换单独提供的文本样例，筛除无效值后复用平均值函数。
  4. 核对有效值和无效值数量，并复核均值；main() 总控流程为提前完成后的拓展任务。

如果卡住了

  1. 先用一个正常值测试函数，再测试边界值和异常值。
  2. 需要后续计算的函数应使用 return，不能只 print()。
  3. except 中要给出明确结果，例如返回 None，不要静默忽略。
  4. 调用函数前确认前面的函数定义单元已经运行。
  5. calculate_mean() 只接收非空的有效数值列表；文本转换与无效值筛选由前序步骤完成。

提交前检查

  1. 每个函数都有明确输入和返回值。
  2. "unknown" 和 "NA" 不会让整个 Notebook 中断。
  3. 无效值没有被加入有效数值列表。
  4. 有效值与无效值数量之和等于原文本数量；没有有效值时不调用平均值函数。
  5. 已说明哪些函数能在 E05 继续使用。

给学生的提醒

课程准备代码负责载入 JSON 小样本，不要求学生自行读取文件。小样本中的学习时长与出勤率已是有效数值；NA、unknown 只出现在单独提供的文本练习中。重点是把重复规则写清楚，为下一次综合实验做准备。
