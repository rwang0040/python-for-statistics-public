E04 实验前准备卡

适用实验：e04_inclass.ipynb

开始前先确认

  1. 已确认 lab/shared/samples/chapter2_records.json 文件存在，并运行课程准备单元。
  2. 能区分函数的参数、函数体、返回值和调用结果。
  3. 已复习 E03 中的分类、筛选和累计规则。
  4. 知道 float("6.5") 可以转换，而 float("unknown") 会触发 ValueError。

本次实验要完成什么

  1. 把学习时长分类规则写成函数。
  2. 编写平均值函数并说明输入、输出。
  3. 使用 try-except 安全转换字段文本。
  4. 组合函数、循环和判断得到有效值列表。
  5. 编写筛选函数和总控汇总函数。
  6. 使用测试案例核验函数；main() 总控流程为提前完成后的拓展任务。

如果卡住了

  1. 先用一个正常值测试函数，再测试边界值和异常值。
  2. 需要后续计算的函数应使用 return，不能只 print()。
  3. except 中要给出明确结果，例如返回 None，不要静默忽略。
  4. 调用函数前确认前面的函数定义单元已经运行。

提交前检查

  1. 每个函数都有明确输入和返回值。
  2. "unknown" 和 "NA" 不会让整个 Notebook 中断。
  3. 无效值没有被加入有效数值列表。
  4. 已说明哪些函数能在 E05 继续使用。

给学生的提醒

本实验只处理已经取得的字段值，尚不读取文件。重点是把重复规则写清楚，为下一次综合实验做准备。
