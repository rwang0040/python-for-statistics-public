E05 实验前准备卡

适用实验：e05_inclass.ipynb

开始前先确认

  1. 仓库中的 lab/shared/raw/student_survey_raw.txt 存在。
  2. 已复习 with open(...)、readlines()、strip() 和 split()。
  3. 已复习 E04 的函数、try-except 和 None。
  4. 知道课程数据统一使用 UTF-8，本实验固定写 encoding="utf-8"。

本次实验要完成什么

  1. 第一次从外部文本文件读取完整调查数据。
  2. 拆分文本行并统一受控的 ASCII 类别别名。
  3. 安全转换数值和百分数字段。
  4. 批量生成记录、按 student_id 去重并检查缺失值。
  5. 把结果固定保存到 lab/applied-stat-64/chapter2/e05_output 目录。
  6. 只读官方 JSON 检查点并核验结果。

如果卡住了

  1. 先确认打印出的 raw_path 存在，不要随意复制绝对路径。
  2. 先成功解析一行，再编写批量循环。
  3. 字段数量不是 8 时，不要继续按固定位置取值。
  4. 类别统一先清理空白和大小写，再使用映射字典。
  5. 不得把输出路径改到 lab/shared。

提交前检查

  1. 清洗后应有 160 条唯一学生记录。
  2. 重复记录数、学习时长缺失数和出勤率缺失数均已输出。
  3. 输出 JSON 重新读取成功。
  4. 与官方检查点的记录数、字段和全部记录比较均已完成。
  5. 已说明 E02–E04 中哪些知识在本实验中被复用。

给学生的提醒

文件能够打开不代表数据已经可以分析。读取、拆分、转换、结构化和核验是彼此不同的步骤。
