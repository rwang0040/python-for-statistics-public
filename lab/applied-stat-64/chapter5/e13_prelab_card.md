# E13 实验前准备卡

适用实验：`e13_inclass.ipynb`

## 开始前先确认

1. 已确认 `lab/shared/analysis/student_eda.csv` 存在。
2. 如需继续个人成果，已确认 E12 输出文件存在且核验通过。
3. 已复习 Chapter 5A 中直方图、频数图、箱线图和个体点的用途。
4. 能根据变量类型区分数值分布、分类频数和分组分布问题。

## 本次实验要完成什么

1. 检查一人一行的学生分析视图。
2. 比较两种分箱下的成绩直方图。
3. 绘制专业频数图。
4. 使用箱线图和个体点比较专业间成绩分布。
5. 修正一张容易误导的频数图并导出代表性图形。

## 如果卡住了

1. 先检查当前使用的是哪张表、哪一列以及变量类型。
2. Seaborn 图形异常时，检查 `data`、`x`、`y`、`order` 和 `ax`。
3. 标签或布局重叠时，检查 `ax.set()`、刻度旋转和 `tight_layout()`。
4. 个人成果核验失败时应先修正；需要继续时可把输入开关改为 `False`。

## 提交前检查

1. 三类图形均回答了明确的问题。
2. 图形具有清楚的标题、横轴和纵轴标签。
3. 解释没有把样本差异写成总体结论或因果结论。
4. 已导出 `e13_major_score_distribution.png` 并完成实验小结。
