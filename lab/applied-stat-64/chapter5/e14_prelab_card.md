# E14 实验前准备卡

适用实验：`e14_inclass.ipynb`

## 开始前先确认

1. 已确认 `student_eda.csv` 和 `learning_wave.csv` 两张官方分析视图存在。
2. 如需继续个人成果，已确认 E11、E12 输出文件存在且核验通过。
3. 已复习 Chapter 5B 中散点图、趋势线、折线图和热力图的用途。
4. 能说明“一名学生”和“一名学生在一个轮次”是不同的观测单位。

## 本次实验要完成什么

1. 使用散点图和颜色分组探索变量关系。
2. 添加描述性趋势线并计算相关系数。
3. 汇总四轮记录并绘制有序变化图。
4. 绘制相关热力图。
5. 使用已有三张图完成一份 EDA 短报告。

## 如果卡住了

1. 先确认当前任务应使用 `student_df` 还是 `wave_df`。
2. 折线图异常时，先检查是否已经按轮次和专业汇总。
3. 热力图异常时，确认相关矩阵只包含数值列。
4. 写结论时先陈述图形事实，再说明解释边界和后续问题。

## 提交前检查

1. 已导出散点图、轮次图和热力图。
2. 已保留轮次成绩的有效样本量口径。
3. EDA 短报告包含问题、图形事实、解释边界和后续问题。
4. 没有把相关关系、专业差异或轮次变化解释为因果关系。
