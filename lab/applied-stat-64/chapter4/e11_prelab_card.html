E11 实验前准备卡

适用实验：e11_inclass.ipynb

开始前先确认

  1. 已确认 lab/shared/raw/learning_records_raw.csv 存在。
  2. 已复习 E10 的类型转换、缺失检查和去重流程。
  3. 已复习 Chapter 4C 中的 groupby()、agg()、crosstab()、pivot_table() 和 melt()。
  4. 知道四轮记录的主键是 student_id + wave。

本次实验要完成什么

  1. 清理并核验四轮学习记录。
  2. 按轮次完成基础和多指标汇总。
  3. 生成频数表与交叉表。
  4. 完成宽表与长表转换。
  5. 导出 640 行清洗记录供 E12 使用。

如果卡住了

  1. 分组前先检查字段类型和复合主键。
  2. 样本量不一致时区分 size() 与 count()。
  3. 透视后先检查 shape 和列名，再执行 melt()。
  4. 不要为了得到完整表格而填补真实缺失值。

提交前检查

  1. 清理后为 160 名学生、640 条唯一学生—轮次记录。
  2. 四个轮次均存在。
  3. 出勤率、测验成绩和任务完成率缺失数分别为 4、11 和 5。
  4. 已导出个人 E11 成果并完成实验小结。
