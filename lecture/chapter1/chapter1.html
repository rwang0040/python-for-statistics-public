命名规范

在统计项目中，良好的命名习惯至关重要。对比以下两种写法，哪一种在三个月后还能让你一眼看懂代码的含义？

  • 反面教材：a = 500
  • 推荐规范：sample_size = 500

PEP-8 命名规范

  1. 组成：字母、数字、下划线，不能数字开头。
  2. 风格：蛇形命名法(snake_case)。
  3. 大小写敏感：data \(\neq\) Data。
  4. 避免冲突：
    • 严禁使用关键字 (if, for)。

经典排错：NameError 与“大小写陷阱”

  • 阅读公式或表格时，我们有时会看到不同大小写的符号。
  • 但在 Python 中，变量名是严格区分大小写的！
  • 拼写错误或大小写不一致，会触发最常见的 NameError（变量未定义）。

数据规范与学术意识

四条基本原则

  1. 数据真实性
    严禁篡改或伪造数据。
  2. 规范分析
    分析过程必须可复现。
  3. 隐私保护
    保护个人隐私数据。
  4. 工具核验
    AI 或其他工具生成的代码，必须经过运行、检查和解释。
